# 咩记 · 每日任务

<img src="icon-512-round.png" width="120" align="right">

一只小羊陪你记每天的工作任务。打开就用，不用注册，数据只存在你自己的浏览器里。

**网址：** https://jomoreds.github.io/sheep-todo/

## 功能

- **语音记任务**：点麦克风一口气说好几件事，自动拆成多条，识别时间（“下午三点半”）、日期（“明天”“周五”）和分类
- **翻页看每天**：左右滑动、点上方日期或用 ← → 键翻页；特效可选翻书 / 卡片 / 淡入
- **划线完成**：点圆圈打勾，文字划线，自动收进“已完成”
- 星标重要事项、左滑删除（可撤销）、点文字直接改、点标签切换分类
- 之前没做完的任务一键挪到今天
- 一键复制日报，粘贴到企业微信 / 微信
- 统计：近 7 天完成率、连续天数、16 周热力图、分类占比
- 到点提醒、深色模式、离线可用、导出 / 导入备份
- 可安装到手机主屏 / 电脑桌面，图标是小羊

## 语音说明

网页语音依赖浏览器自带的识别服务：**iPhone Safari、Edge 浏览器**在国内可直接用；Chrome 需要连谷歌服务器，国内不可用。
不支持时会自动切换到文本框，用输入法的麦克风（讯飞、搜狗、系统键盘）说话，同样能自动拆分成多条任务。

## 文件

单文件网页 `index.html`，没有任何外部依赖（不加载国外字体或 CDN），`sw.js` 提供离线缓存，`manifest.webmanifest` 和图标用于安装到桌面。
